# 起雾的窗户

下雨天的一扇窗。玻璃上起了一层雾，用手指擦一擦，看看窗外。

**在线玩：** https://2596441336-cmyk.github.io/foggy-window/

## 怎么玩

- **擦雾**：手指在屏幕上划，雾气被擦掉，露出窗外。擦过的地方会聚出几滴水慢慢往下流。
- **写字画画**：选「指尖」写字，「手掌」大片地擦，「哈气」让雾重新回来。
- **雾会回来**：过一会儿，擦掉的地方会慢慢重新起雾，速度可以调，也可以关掉。
- **雨珠**：窗外的雨点打在玻璃上，大雨珠会顺着玻璃滑下来，冲开一道水痕。
- **雨**：小雨、大雨、雷雨（会打闪、打雷），有现场合成的雨声。
- **存图**：把这扇窗现在的样子存到相册。

## 窗外是什么

- **随机街景**：雨夜东京小巷、老上海弄堂、欧洲石板街、海边小镇、纽约街角、乡间小路，每种都有黄昏、深夜、阴天，每次都是现场画出来的、不一样的街。
- **你的照片**：拍一张，或者从相册里选一张。
- **实时窗外**：打开后置摄像头，透过这扇起雾的窗看你眼前的世界。

照片和相机画面只在你的手机上处理，不会上传到任何地方。

## 装到手机上

iPhone：用 Safari 打开网址 → 分享 → 添加到主屏幕。
安卓：用浏览器打开网址 → 菜单 → 添加到主屏幕 / 安装应用。

## 技术

纯静态网页（HTML + Canvas + 原生 JavaScript），无需构建，GitHub Pages 托管。

```
js/scenes.js   随机街景生成（简单透视投影）
js/glass.js    雾气、擦拭、回雾、雨珠折射、水痕、闪电
js/audio.js    现场合成的雨声和雷声
js/app.js      界面、照片、相机、存图
```
